# Doceme Pitch Deck Website

This is a static website version of the DOCEME pitch deck.

## Publish with GitHub Pages
1. Extract the ZIP file.
2. Open your GitHub repository.
3. Upload `index.html` and the entire `slides` folder (keep the folder name `slides`).
4. Commit the changes to the `main` branch.
5. Open **Settings → Pages**.
6. Under **Build and deployment**, choose **Deploy from a branch**.
7. Select branch **main** and folder **/(root)**, then click **Save**.
8. Wait a few minutes. The site URL will appear in the Pages settings.

Important: `index.html` must be at the selected publishing root, alongside the `slides` folder. Do not upload only the PPTX file.
